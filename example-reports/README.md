# Beacon Analysis example reports

Open [the report catalog](index.html) in the published Pages site or after downloading this branch. HTML shown on github.com is source text; GitHub Pages provides the browsable reports.

This branch contains curated public derivatives, not complete analysis runs. Parquet data are omitted; summary measurements remain unchanged. Example radio plots are explicitly labelled and watermarked per band. The original path in each plot-index CSV identifies its source analysis; publication_path and publication_plot_type describe the public target. The 2026 classroom and HBLL reports share 46 actual HBLL radio plots after exact measurement checks. Unlinked classroom peak-exposure CDFs/tables are omitted.
